# Venkateswaran S - Personal Portfolio

This repository contains the source code for my personal portfolio website. The website showcases my professional background, projects, patents, and miscellaneous interests.

## Features

- **About Me**: A brief introduction to my background and interests.
- **Projects**: A section highlighting my key projects.
- **Patents**: Details of patents I have worked on.
- **Miscellaneous**: Other interests and achievements.
- **Social Links**: Links to my GitHub, LinkedIn, and email for easy connection.

## Technologies Used

- **HTML**: For structuring the content.
- **CSS**: For styling the website.
- **Font Awesome**: For social media icons.
